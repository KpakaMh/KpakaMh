**Academic Project | Systems Biology · Workflow & Network Analysis**

Study of the effects of nitrogen availability on gene expression and gene interaction networks.

**Tools:** `MeV` · `Cytoscape` · `TAIR` · `ePlant`

### 3. [BioAssayLab](https://github.com/KpakaMh/BioAssayLab)
**R | Shiny | Biostatistics**

A dose-response analysis application for biological assay data.
- Nonlinear regression using the four-parameter logistic model (4PL).
- Dose-response curve analysis.
- $\text{IC}_{50}$ and $\text{EC}_{50}$ estimation.

**Tools:** `R` · `Shiny` · `Nonlinear Regression`

---

### 4. [BioTwin](https://github.com/KpakaMh/bioreactor-simulation)
**Python | Scientific Computing | Docker**

A digital twin application for bioreactor simulation.
- Batch and Fed-Batch culture modeling.
- Microbial growth kinetics based on the Monod model.
- Ordinary differential equation (ODE) solving.
- Oxygen transfer modeling using the $k_La$ parameter.
- Interactive simulation and visualization.

**Tools:** `Python` · `SciPy` · `Pandas` · `Dash` · `Plotly` · `Docker`

A collection of statistical workflows and case studies covering statistical methods applied to biological and biomedical data.
- Descriptive statistics and probability.

- Statistical assumptions, diagnostic tests, and multiple comparison procedures.

**Tools:** `R` · `RStudio`
